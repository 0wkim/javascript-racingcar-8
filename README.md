# javascript-racingcar-precourse

# 프리코스 2주차 미션 - 자동차 경주
----------------

## 기능 목록


### 1. 사용자 입력 저장

- 자동차 이름 입력 받기
    - 자동차 이름은 5자 이하만 가능
    - 자동차 이름은 쉼표로 구분 

- 시도 횟수 입력 받기



### 2. 자동차 전진 함수 구현

- 0에서 9 사이 값 중, 3 이하는 멈춤
- 0에서 9 사이 값 중, 4 이상은 전진
- Random.pickNumberInRange()를 사용하여 무작위 값을 구한다.



### 3. 우승자 출력
    
- 우승자는 한 명 이상일 수 있다.
- 우승자가 여러 명일 경우, 쉼표를 이용해서 구분한다.



### 4. 실행 결과 출력

- 차수에 따른 자동차 전진을 출력한다.



### 5. 예외처리 

[사용자 입력]
- 자동차 이름을 입력하지 않은 경우
- 시도횟수를 입력하지 않은 경우
- 자동차 이름이 6자 이상인 경우
- 자동차 이름이 중복되는 경우
- 자동차 개수가 1개인 경우 (자동차 개수가 최소 2개 이상이 될 것) 

[입력값 제한]
- 자동차 개수 제한 -> 제한하지 않음
- 시도 횟수 제한 -> 50회 이하로 제한
